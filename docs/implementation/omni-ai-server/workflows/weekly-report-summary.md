# Weekly Report Summary Workflow

Status: Planned

정해진 기간의 쪽지 중 주간보고에 해당하는 내용을 파트 또는 업무 단위로 분류하고 요약한다.

## Initial Contract

- 입력: 대상 기간, 후보 메시지, 조직·파트 식별 정보
- 출력: 파트별 요약, 주요 항목, 원본 메시지 참조

## Boundary

Schedule 저장, 실행 시각 계산, 온라인 상태 판단과 결과 쪽지 전달은 AI Orchestrator와 Messenger Application 영역의 책임이다.
