# Troubleshooting

> Role: 개발 중 발생한 문제, 원인, 해결, 후속 조치를 기록하는 문서  
> Status: Planned

---

## Purpose

이 문서는 구현 중 발생한 문제를 나중에 다시 추적할 수 있도록 기록한다.

문제가 설계 방향을 바꾸는 수준이라면 `docs/decisions/`에 ADR을 추가하고, 진행 상태에 영향을 주면 `docs/roadmap.md`도 함께 갱신한다.

---

## Troubleshooting Template

```md
## YYYY-MM-DD. 문제 제목

Status: Open | Resolved | Deferred

### Problem

어떤 문제가 발생했는가.

### Impact

어떤 기능이나 흐름에 영향을 주었는가.

### Cause

원인은 무엇이었는가.

### Fix

어떻게 해결했는가.

### Follow-up

추가로 확인하거나 개선할 것은 무엇인가.

### Related

관련 문서, ADR, 이슈가 있다면 연결한다.
```
