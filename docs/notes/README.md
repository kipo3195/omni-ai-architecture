# Development Notes

> Role: 개발 중 발생한 구현 메모, 트러블슈팅, 실험 결과, Phase별 회고를 모으는 디렉터리  
> Status: Planned

---

## Purpose

`docs/notes/`는 개발 중 생기는 실전 기록을 남기는 공간이다.

설계 결정으로 승격할 만큼 중요하면 `docs/decisions/`에 ADR로 정리하고, 진행 상태 변경은 `docs/roadmap.md`에 반영한다.

---

## What Goes Here

- 구현 중 마주친 문제와 해결 과정
- Queue, WebSocket, Tool Calling, Context 처리 관련 트러블슈팅
- Phase별 작업 메모와 회고
- 실험 결과
- 추후 ADR로 승격할 수 있는 임시 판단

---

## What Does Not Go Here

- 전체 아키텍처 설명: `docs/architecture.md`
- 주요 설계 결정 요약: `docs/design-decisions.md`
- 확정된 ADR: `docs/decisions/`
- Phase 상태 관리: `docs/roadmap.md`
